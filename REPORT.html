1. Project Summary

1.1 Paper Overview

TradingAgents (Xiao et al., 2024) is a multi-agent LLM framework for financial trading that simulates a real-world trading firm. The system employs multiple specialized LLM-based agents organized in a pipeline:

Market Analyst Sentiment Analyst News Analyst Fundamentals Analyst
↓
Bull Researcher ↔ Bear Researcher
↓
Research Manager
↓
Trader
↓
Aggressive ↔ Conservative ↔ Neutral
↓
Portfolio Manager → Final Decision

The paper reports (Table 1) that TradingAgents achieved 26.62% cumulative return on AAPL, 24.36% on GOOGL, and 23.21% on AMZN over Jan-Mar 2024, significantly outperforming Buy & Hold and technical indicator baselines.

1.2 Reproduction Target

We reproduce the multi-agent decision pipeline for NVDA and AAPL on historical dates in January 2024, verifying the pipeline executes end-to-end and producing trade decisions.

Key Positive Finding

The full multi-agent pipeline executes correctly with DeepSeek — all 4 analysts, 2 researchers, research manager, trader, 3 risk debaters, and portfolio manager complete their roles. SEC EDGAR fundamental data was retrieved successfully with high-quality analysis (e.g., NVDA Q3 FY2024: revenue $18.12B, +206% YoY, gross margin 74.0%). When data sources failed, agents correctly reported "DATA_UNAVAILABLE" and declined to fabricate data, producing placeholder reports instead.

Key Limitation: Sentiment & News Data Are Placeholders

Yahoo Finance rate limiting (HTTP 429) prevented market/technical/news data retrieval. StockTwits (403) and Reddit (timeout) also failed. However, the Sentiment Analyst and News Analyst still generated "data-unavailable" placeholder reports rather than fabricating data — a positive robustness finding. The JSON flags has_sentiment_data: true and has_news_data: true reflect that an LLM produced text, not that actual data was retrieved. All decisions were driven solely by SEC EDGAR fundamental data.

4.3 Impact Analysis

Finding: Risk debate has no effect on final decision rating

Both test cases received identical ratings with and without the risk debate component. This suggests the Portfolio Manager largely follows the Research Manager's recommendation regardless of the risk analysts' input.

Nuances observed:

  • Partial execution: Even with rounds=0, the Aggressive Analyst gets one turn (the conditional logic routes to Portfolio Manager immediately after).
  • Reasoning depth: Baseline Portfolio Manager references all three risk perspectives; ablation version references only Aggressive Analyst's points.
  • Speed: AAPL ablation was ~26.0% faster (145.7s vs 197.1s) as expected.
  • Decision stability: Core signal comes from fundamentals + bull/bear debate, not risk debate.

6. Conclusions

6.1 What Is Reproducible

  • Multi-agent pipeline execution: ✅ Fully reproducible with a different LLM provider (DeepSeek)
  • Fundamental analysis quality: ✅ SEC EDGAR data retrieval and analysis are high quality
  • Decision production: ✅ System consistently produces clear 5-tier ratings
  • Robustness to data failures: ✅ System handles missing data gracefully

6.2 What Is Not Reproducible

  • Full backtest comparison: ❌ Yahoo Finance rate limiting prevented daily backtest
  • Market technical analysis: ❌ No OHLCV, RSI, MACD, or moving averages
  • Sentiment analysis: ❌ StockTwits (403) and Reddit (timeout) both failed. The Sentiment Analyst generated a placeholder report with a default Neutral score (5.0/10, Low confidence) but no actual sentiment data was retrieved. The JSON flag has_sentiment_data: true is misleading — it means "agent produced text," not "data was available."
  • News analysis: ❌ Yahoo Finance news (HTTP 429) and FRED macro (key not set) both failed. The News Analyst generated a placeholder report stating "zero usable observations" but no actual news or macro data was retrieved. The JSON flag has_news_data: true is similarly misleading.
  • Exact numerical comparison: ❌ Different LLM + missing data = not comparable to Table 1

6.3 Recommendations

  1. Use Alpha Vantage as fallback data source to avoid Yahoo Finance rate limits
  2. Set FRED_API_KEY for macro economic data (free)
  3. Run 3-5 trials per condition due to LLM non-determinism
  4. DeepSeek is ~10x cheaper than OpenAI for comparable results
  5. Cache Yahoo Finance responses locally for true reproducibility
